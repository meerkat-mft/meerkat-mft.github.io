# Security policy

This repository holds the static website at [mmft.dev](https://mmft.dev). It contains no server code and processes no user data.

## Reporting a vulnerability

Do not open a public issue for a security problem.

- **Problems with the website** (content injection, a misconfigured domain, a broken security header, a leaked secret in this repository): use GitHub's [private vulnerability reporting](https://github.com/meerkat-mft/meerkat-mft.github.io/security/advisories/new) on this repository.
- **Problems with Meerkat MFT itself** (the orchestrator, agents, CLI or console): report them to the [mmft repository](https://github.com/meerkat-mft/mmft/security/advisories/new) and read its [security policy](https://github.com/meerkat-mft/mmft/blob/main/SECURITY.md).

Include what you found, where, and how to reproduce it.

The same information is published at <https://mmft.dev/.well-known/security.txt>.

This is a spare-time project with one maintainer, so response times are not guaranteed.
